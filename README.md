# GitHub Tool
A custom tool that I made as a commission by one of my friends, whom found it tedious to manually input commands. The largest problem he listed was GitHub Desktop, amongst the other Git tools, never really initialized Git LFS on any of the projects. That's when I had the bright idea to create this tool, and partially due to the available options being superfluous, requiring extensive and unconventional setups.

## Why Open Source?
> **NOTE:** Please do **NOT** sell this tool. Feel free to modify it and personalize it, but this tool **should** remain free.

Since this tool helped my friend, I thought it would be a good idea to make this project open-source! That way, many others can make their own forks and expand on the idea. If you end up using the code, please credit me (this is not mandatory, but would help me tremendously!)

## Supported Project Types
- Java
- Godot
- C++
- Unreal Engine
- Unity
- Lua

## Project Types Setup Guide
To whom it may concern, you are able to add custom project types. This will require a folder containing a ``.gitignore`` file and a ``.gitattributes`` file. This is because the software scans the content root folder for subfolders with the files in question.

## Installation & Usage Guide
Extract the zip folder, or use ``git clone https://github.com/Boufya/git-tool.git``. Double-click the ``git_tool.py`` file and it will popup a command prompt as well as the actual application. Head over to the Credentials tab
